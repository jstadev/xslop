# Code of conduct

This project follows the Contributor Covenant, version 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be respectful, assume good intent, and criticise code, not people. Harassment and personal attacks are not accepted.

To report a problem, use "Report a vulnerability" on the Security tab of the repository and choose the title "Conduct". The maintainers read every report and keep the name of the reporter private.
