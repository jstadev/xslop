  2. Mutes it on XThe X app hides it too.

Two extras, both off

You are ready

Open x.com. Click the xslop button on slop. A hidden post shows Show and Undo.

What xslop sends

  • Votes. Slop or not slop, the handle, the post id, reply or post, the id of the post it answers, and the post time. Never the text. The account page on x-slop.com can link these posts after the server checks the author.
  • Signals, only if on. For each reply on a post page you open: its handle, its post id and the id of the post it answers. The server does not store which install sent a signal.
  • A random key. xslop makes it on this device and signs each vote with it. Registration sends its public part and the xslop version. It has no name, no email and no link to your X account.
  • Never sent. Your X login or cookies, your own handle, who you follow, your mutes, and any page outside X.

The server stores no IP address, only a short hash of your network range.
