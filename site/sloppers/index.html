What this list means

The extension hides confirmed accounts unless you set strictness to Off. It hides flagged accounts only if you set strictness to Strict. The list records votes and reply behaviour. It does not prove who runs an account.

If one of these accounts is yours, you can appeal. Choose Appeal on its line. You get a short code to put in your X bio, and a person reads every appeal. You never give your password.

How an account gets on this list
