What xslop sends, and what it never sends

Sent to the xslop server

  • Your votes: the account's handle, slop or not slop, the post's id, the id of the post it answers, whether it is a reply or a post, and the time of the post. Never the text of the post.
  • A random install id, a public key and the version of the extension. Your browser makes the key pair and signs every vote with it. The private key never leaves your browser.
  • Only if you turn on signal sharing, for each reply on a post page that you open: the handle of the account that replied, the id of the reply and the id of the post it answers. The server does not store which install sent a signal.

Never sent

  • Your X password, cookies or session. Mute sync and the instant mute run inside your own x.com tab and talk only to x.com.
  • Your own X handle and the accounts you follow.
  • Pages outside x.com. The extension runs on x.com only.
  • A stored copy of your IP address. Every web request shows it to the server, but the server keeps only a salted hash of your network prefix, to spot many installs on one network.
  • The text of a post or a reply, in a vote or in a signal.

This page loads nothing from other servers: no analytics, no ads, no trackers.
