The rules, as the server applies them

Standing and checks decide
A mark from a new install hides and mutes the account for you at once. It counts for the shared list after a person approves it, or after your install earns standing with marks that held up. An automatic listing also needs posts that the server checked, and one side alone cannot confirm an account.
Reply timing, checked by the server
With signal sharing on, the extension sends the handle of a reply and two post ids. The server checks the posts on X and reads the reply time from the ids. Reply timing never changes the status of an account.
Fresh and crowded installs count less
A vote from a new install counts less. Many installs on one network count as fewer voters.
A person reads every appeal
Anyone on the list can appeal. An admin checks each appeal by hand, and an accepted appeal clears the account.

The list started from the public X list "ai slop posters" by @dillon_mulroy, 793 accounts at import. A second import on 13 November 2026 took the accounts of the public list Clankwall that have at least 2 flagged replies, where flagged replies are at least half of the sampled replies: 1,430 accounts, 1,046 of them new. Those accounts start as confirmed and can appeal like any other.
